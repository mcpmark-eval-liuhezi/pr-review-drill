# Review Checklist

The starting checklist for the review drill.

1. Read the pull request description before opening the diff.
2. Make sure the branch is up to date with the default branch.
3. Review the complete diff end to end before leaving any comments.
4. Check that continuous integration is green.
5. Focus comments on the code, not the person.
6. Close the review with an explicit approve or request-changes decision.
7. Confirm the new item was appended at the end of the checklist.
